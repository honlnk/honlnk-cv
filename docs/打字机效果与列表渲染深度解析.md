# 打字机效果与列表渲染深度解析

## 📖 概述

本项目实现了独特的打字机动画效果来展示项目经历，同时支持嵌套列表结构。项目采用了一种创新的**混合方案**：在保留打字机效果的同时，通过层级元数据和 CSS 样式实现视觉上的嵌套层次感。

**核心设计**：
- **解析层**：维护语义准确的嵌套 `ListItem[]` 结构
- **渲染层**：扁平化为 `{ content: string, level: number }[]`，通过 `padding-left` 和颜色区分层级
- **视觉效果**：奇数层级和偶数层级使用不同的颜色标记，清晰易读

---

### 2. 缩进级别计算（`useResumeData.ts:366-369`）

```typescript
function getIndentLevel(line: string): number {
  const match = line.match(/^(\s*)/)
  return match ? Math.floor(match[1].length / 2) : 0
}
```

**工作原理**：
- 检测行首空格数量
- 每 2 个空格 = 1 级缩进
- 用于判断列表项的层级关系

**示例**：
```

"  二级项"         → indentLevel = 1
"    三级项"       → indentLevel = 2
```

### 3. 嵌套列表构建算法（`useResumeData.ts:374-403`）

```typescript
function addNestedListItem(list: ListItem[], item: ListItem, indent: number): void {
  if (indent === 0) {
    // 顶级项，直接添加
    list.push(item)
  } else {
    // 查找父级项
    const parentIndex = list.length - 1
    if (parentIndex >= 0) {
      let parent = list[parentIndex]

      // 向上查找合适的父级
      let currentIndent = indent - 1
      while (currentIndent > 0 && parent.children && parent.children.length > 0) {
        const nextParent = parent.children[parent.children.length - 1]
        if (nextParent) {
          parent = nextParent
          currentIndent--
        } else {
          break
        }
      }

      // 添加到父级的 children 中
      if (!parent.children) {
        parent.children = []
      }
      parent.children.push(item)
    } else {
      // 没有父级，作为顶级项
      list.push(item)
    }
  }
}
```

## 🎨 渲染层：扁平化的必要性

### 1. 打字机效果的要求

打字机效果的核心需求：
1. **逐行处理**：一行完成后才开始下一行
2. **逐字符追加**：每个字符按时间间隔依次出现
3. **动态高度更新**：每次追加字符时更新容器高度
4. **流畅动画**：避免 DOM 结构的频繁重排

### 2. 扁平化算法（当前实现）

**旧方案（已废弃）**：拼接空格前缀
```typescript
const flattenHighlights = (items: ListItem[]): string[] => {
  const result: string[] = []
  const flatten = (items: ListItem[], level = 0) => {
    for (const item of items) {
      const prefix = '  '.repeat(level)  // ❌ 空格前缀会被 HTML 折叠
      result.push(prefix + item.content)
      if (item.children && item.children.length > 0) {
        flatten(item.children, level + 1)
      }
    }
  }
  flatten(items)
  return result
}
```

**新方案（当前实现）**：保留层级元数据（`BaseProjectCard.vue:23-46`）
```typescript
const flattenHighlights = (items: ListItem[]): Array<{ content: string; level: number }> => {
  const result: Array<{ content: string; level: number }> = []
  const flatten = (items: ListItem[], level = 0) => {
    for (const item of items) {
      result.push({
        content: item.content,  // ✅ 纯净内容，不拼接空格
        level                   // ✅ 保留层级信息
      })
      if (item.children && item.children.length > 0) {
        flatten(item.children, level + 1)
      }
    }
  }
  flatten(items)
  return result
}

// 适配 better-typing 要求的纯文本数组
const flattenedHighlights = flattenHighlights(props.project.highlights)
const adaptedProject = {
  title: props.project.title,
  highlights: flattenedHighlights.map(item => item.content)  // 提取纯文本用于打字机
}
```

**改进点**：
1. 不再拼接空格前缀（解决 HTML 空格折叠问题）
2. 保留层级元数据（用于后续样式控制）
3. 分离关注点（打字机用纯文本，渲染用层级信息）

### 3. 显示动画详解（`better-typing.ts:31-71`）

```typescript
export async function showTemplate(
  template: string[][],
  defaultValue: DefaultValue[],
  selectIndex: number,
  heightElement: HTMLElement,
  heightDict: Record<number, number>
): Promise<void> {
  // 1. 初始化当前行的模板为空数组
  template[selectIndex] = defaultValue[selectIndex].highlights.map(() => '')

  // 2. 清空之前可能存在的删除定时器
  if (removeTimers.value[selectIndex] != undefined) {
    removeTimers.value[selectIndex].forEach(timer => clearTimeout(timer))
  }

  // 3. 初始化添加定时器数组
  activeTimers.value[selectIndex] = []

  // 4. 遍历每一行
  for (const [row, line] of defaultValue[selectIndex].highlights.entries()) {
    const promiseList: Promise<void>[] = []

    // 5. 遍历当前行的每一个字符
    line.split('').forEach((char, ip) => {
      promiseList.push(
        new Promise<void>(resolve => {
          const timer = setTimeout(() => {
            const text = template[selectIndex][row]
            template[selectIndex][row] = text + char  // ← 追加字符
            heightDict[selectIndex] = heightElement.scrollHeight  // ← 更新高度
            resolve()
          }, time * ip)  // ← 每个字符延迟 10ms
          activeTimers.value[selectIndex].push(timer)
        })
      )
    })

    // 6. 等待当前行的所有字符完成后再进入下一行
    await Promise.all(promiseList)
  }
}
```

### 5. 隐藏动画详解（`better-typing.ts:79-126`）

```typescript
export async function hideTemplate(
  template: string[][],
  defaultValue: DefaultValue[],
  selectIndex: number,
  heightDict: Record<number, number>,
  delay: number = 500
): Promise<void> {
  heightDict[selectIndex] = 0  // ← 立即设置高度为 0（触发收起动画）

  const templateLen = template[selectIndex].length

  // 清除添加定时器
  if (activeTimers.value[selectIndex] != undefined) {
    activeTimers.value[selectIndex].forEach(timer => clearTimeout(timer))
  }

  // 初始化删除定时器数组
  removeTimers.value[selectIndex] = []

  // 延迟后强制清空（确保动画结束）
  setTimeout(() => {
    if (removeTimers.value[selectIndex] != undefined) {
      removeTimers.value[selectIndex].forEach(timer => clearTimeout(timer))
      template[selectIndex] = defaultValue[selectIndex].highlights.map(() => '')
    }
  }, delay)

  // 从最后一行开始反向删除
  for (let row = 0; row < templateLen; row++) {
    const text = template[selectIndex][templateLen - 1 - row]
    if (text) {
      const promiseList: Promise<void>[] = []

      text.split('').forEach((char, i) => {
        promiseList.push(
          new Promise(resolve => {
            const timer = setTimeout(() => {
              // 从末尾逐字符删除
              template[selectIndex][templateLen - 1 - row] = text.slice(0, text.length - 1 - i)
              resolve()
            }, i * time)
            removeTimers.value[selectIndex].push(timer)
          })
        )
      })

      await Promise.all(promiseList)
    }
  }
}
```

## ⚖️ 设计权衡

### 当前方案的优劣

#### ✅ 优点

1. **流畅的打字机动画**：逐字符显示效果生动有趣
2. **实现简单**：扁平化数据结构易于处理
3. **性能优秀**：单一层级 DOM，避免频繁重排
4. **高度自适应**：`scrollHeight` 实时更新，动画自然

#### ❌ 缺点

1. **语义不够准确**：嵌套层级通过空格前缀表示，而非 DOM 结构

3. **可访问性弱**：屏幕阅读器无法识别层级关系
4. **复制粘贴问题**：用户复制时会保留空格前缀

```typescript
interface FlatItem {

const flattenHighlights = (items: ListItem[]): Array<{ content: string; level: number }> => {
  const result: Array<{ content: string; level: number }> = []
  const flatten = (items: ListItem[], level = 0) => {
    for (const item of items) {
      result.push({
        content: item.content,  // ✅ 纯净内容，不拼接空格
        level                   // ✅ 保留层级信息
      })
      if (item.children && item.children.length > 0) {
        flatten(item.children, level + 1)
      }
    }
  }
  flatten(items)
  return result
}
```
